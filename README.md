### **Linux Installation**

#### Check Python
```bash
python --version
```
*Python 3.12.11*  

#### Create and Activate a Virtual Environment
```bash
python -m venv .venv
```
*This will create a virtual environment in the hidden folder, `.venv`*
```bash
source .venv/bin/activate
```
*This will activate this environment, we are now ready to install Ray*

#### Install Ray:
```bash
pip install -U "ray[default]"
```
